# Upwork integration boundary

No Upwork connection is implemented in the sample-data phases.

## Requires confirmed official access

Before implementation, official documentation and granted scopes must confirm access for job discovery, client metadata, profile reads or writes, proposal submission, application status, messaging, contracts, and Connect-related data. A capability is unavailable until both the official interface and the user's granted permission are verified.

## Always human-controlled

The product requires explicit review and approval before proposal submission, sending a message, accepting a contract, changing a profile, or changing pricing/bid information. If an authorized API does not support an action, the dashboard provides a copy/review workflow for the user to complete manually.

## Prohibited approaches

Browser scraping, CAPTCHA or anti-bot bypass, session-cookie reuse, rate-limit evasion, credential storage, impersonation, spam, and unofficial account automation are outside the architecture.
